# 神煞名称、定义与计算规则

更新：2026-10-22。本文是 Daymark 的研究与实现规格草案，尚未接入日历。中文名称为主键，英文为解释性译名，并非统一标准术语。

## 1. 范围与基本概念

“神煞”是传统术数中依干支关系查出的符号。神常指传统上偏吉的标记，煞常指偏凶的标记，但并非所有名称都能简单分为吉凶。本文只说明传统文化含义和匹配条件，不据此判断疾病、寿命、婚姻结果或现实事件。

神煞没有一份跨流派统一的完整名单。本稿整理 **23 个常见名称**：天乙、文昌、天德、月德、禄神、羊刃、将星、劫煞、灾煞、亡神、孤辰、寡宿、元辰、白虎、丧门，以及驿马、桃花、华盖、红鸾、天喜、空亡、魁罡，以及第一批新增的十恶大败。它是明确范围的首批目录，不是“所有神煞大全”。

必须区分三个计算环境：

| 环境 | 参照资料 | 可以声称什么 |
| --- | --- | --- |
| 八字本命 `natal` | 出生年、月、日、时四柱 | 某柱按某规则匹配某标记 |
| 个人日期匹配 `personal-date` | 出生资料作锚点，所选日期作目标 | 某日期的干或支符合该人的参照规则；属于另行定义的日期匹配功能 |
| 公共历日 `calendar` | 所选日期的年、月、日干支 | 可计算明确的历日规则；不能凭日期生成“每个人的本命神煞” |

择日神煞不能由八字表直接替代。尤其白虎、天德、天喜等同名项目，须保留所属体系。当前 Daymark 没有出生资料输入，已有干支和近似节气也不足以提供完整个人八字功能。

## 2. 统一的计算约定

以下是**本项目草案选择**，不是宣称各派一致。

- 天干顺序及索引：`甲乙丙丁戊己庚辛壬癸`，0–9。
- 地支顺序及索引：`子丑寅卯辰巳午未申酉戌亥`，0–11。
- `mod(n, m) = ((n % m) + m) % m`；向后增加索引称“顺行”，减少称“逆行”。不用含糊的“前一位”代替公式。
- 八字年柱采用立春交接；月柱采用十二“节”的交接，非农历初一。寅月始于立春，依次为惊蛰卯、清明辰、立夏巳、芒种午、小暑未、立秋申、白露酉、寒露戌、立冬亥、大雪子、小寒丑。
- 本项目如实现日期预览，暂以所选时区当地中午取年月柱；日柱按当地民用午夜换日。它是日历产品约定，不涵盖子初 23:00 换日、真太阳时等其他排盘约定。
- 完整出生排盘需独立指定出生时刻、地点/时区、夏令时与换日规则。未知时辰则省略时柱，输出 `partial`，不能补造时柱或声称“完整未命中”。
- 节气交接时刻应使用经过验证的历算来源。当前应用使用近似值，交节附近须显示计算限制，不能将现有中午取值直接用作精确出生排盘。

### 锚点与目标

规则分为“用什么查”（锚点）和“查什么”（目标）。例如甲日干对应天乙的丑、未，意思是**目标地支**为丑或未才命中，不是所有甲日自动带天乙。

本稿 `natal-common-v1` 的约定：

- 天乙、文昌：年干、日干各查一次；禄神、羊刃：日干。
- 三合组规则：年支、日支分别查；每个命中保留来源，不把两种锚点混成一个结论。
- 天德、月德：月支；孤辰、寡宿、红鸾、天喜：年支。丧门须区分出生年支候选版与流年版。
- 以上规则默认在已知四柱查目标，包含锚点所在柱；空亡也按日柱旬查已知柱支，日支自身数学上不会落空。
- 魁罡只查日柱本身。元辰另需传统分类参数。白虎须先选定体系，不能套用这一通用约定。
- `personal-date` 则以出生资料为锚点，只检查所选日期日干、日支；不把目标日期的年份当出生年份。该功能不等同于完整岁运推断。

### 7.3 丧门

此处记录常见年支相对位置候选版，明确公式为 `sangmen = mod(yearBranch + 2, 12)`，即子年寅、丑年卯，依次顺推。[S5] 可直接支持流年太岁安置关系。若以出生年支为锚点查命盘柱支，则是另一常见用法，当前尚缺已逐条核对的本命原典定位，暂列 `pending-source`，不能宣称 [S5] 已验证本命用法。

例：按该候选公式，出生年支子，目标支寅会匹配丧门；生产计算应待来源核对完成。它可能与其他规则同时命中，不得按优先级删除其中一条。

## 8. 元辰：需要额外分类参数

依 [S1] 元辰篇和 [S4] 所载传统双向规则，采用下列显式版本：

1. 取出生年支 `y`；相冲支为 `mod(y + 6, 12)`。
2. 年干甲、丙、戊、庚、壬为阳；乙、丁、己、辛、癸为阴。
3. 传统“阳男、阴女”组取 `mod(y + 7, 12)`；“阴男、阳女”组取 `mod(y + 5, 12)`。
4. 在目标柱支中查该支。

例：甲子年，传统阳男组目标未，阳女组目标巳。两者不能互换；一些现代说明对“冲前／冲后”的措辞相反，所以以公式和例子为准。

这套历史分类参数不能从姓名、邮箱或现代性别认同推断。当前日历不收集此参数，元辰应返回 `not-evaluated`；研究模式可同时展示两列目标，不代替用户选择。此项不是公共日期自身的固定标记。

## 9. 空亡／旬空

六十甲子每十个连续干支为一旬，十个天干只配到十个地支，剩余两支就是该旬的旬空。本稿以**日柱所在旬**为锚点。

| 日柱所在旬 | 日柱序号（甲子=0） | 空亡支 |
| --- | --- | --- |
| 甲子旬 | 0–9 | 戌、亥 |
| 甲戌旬 | 10–19 | 申、酉 |
| 甲申旬 | 20–29 | 午、未 |
| 甲午旬 | 30–39 | 辰、巳 |
| 甲辰旬 | 40–49 | 寅、卯 |
| 甲寅旬 | 50–59 | 子、丑 |

计算：设日柱有效六十甲子序号为 `k`，`start = 10 * floor(k / 10)`，空亡为地支索引 `mod(start + 10, 12)`、`mod(start + 11, 12)`。也可由日干索引 `s`、日支索引 `b` 算旬首支 `mod(b - s, 12)`，再顺推 10、11 位。

来源：[S1] 空亡篇及 [S3] 的六旬表。只接受真实存在的六十甲子组合，例如甲丑应被拒绝。不要把日支自身判为空亡，也不要把旬空自动扩展为截路空亡、四大空亡等其他同名体系。

例：甲子日属甲子旬，目标年支戌、时支亥匹配；甲戌日属甲戌旬，目标支申、酉匹配。公共日历可以显示“本日所属旬的空亡支：戌、亥”，但这不表示当天的日支为空亡。

## 10. 魁罡

采用四日版：日柱属于 `{庚辰、庚戌、壬辰、戊戌}` 即命中。[S2–S3]

它检查整个日柱，不是仅见辰、戌就算，也不是把年柱或月柱上的庚辰当作魁罡日。例：庚辰日命中，甲辰日不命中。公共日历可标“魁罡日（四日版）”，个人四柱的同名判定则仍须使用出生日日柱。

### 10.1 十恶大败：十日柱版

`甲辰、乙巳、丙申、丁亥、戊戌、己丑、庚辰、辛巳、壬申、癸亥`。

传统定义：这十个日柱的日干禄支，落在该日柱所属旬的空亡支中，即“禄入旬空”。“十恶大败”是传统名称，不表示人的道德有问题，也不据此推断必然失败或破财。

| 甲辰 | 寅 | 甲辰旬 | 寅、卯 |
| 乙巳 | 卯 | 甲辰旬 | 寅、卯 |
| 丙申 | 巳 | 甲午旬 | 辰、巳 |
| 丁亥 | 午 | 甲申旬 | 午、未 |

匹配过程：先验证日柱为有效六十甲子组合，再对十项集合做精确匹配；不得只比较日干、日支，或扫描其他柱。年柱为甲辰而日柱为甲子，不命中本规则。

在本命环境，出生日日柱命中即记“十恶大败（日柱十日版）”；公共日历则可把所选日柱命中标作“十恶大败日（十日柱版）”，不将其称为某位用户“命带”。与魁罡同时匹配时分别保留，例如庚辰、戊戌。

验证：穷举六十日柱，必须恰有十项命中，集合与上列完全一致；独立按“日干禄支属于该旬空亡支”计算也应得到同一集合。甲辰 true、甲子 false、甲丑输入错误；只改年柱不改变本规则结果。这是规则表及算术的一致性检查，不替代公历转干支的验证。

## 11. 白虎：先限定体系

“白虎”至少可指岁前十二神、黄黑道十二值神、六壬天将等不同系统；**不能给所有白虎共用一个公式**。

本稿只记录一个可复核的候选：`baihu-suiqian-v1`，以流年太岁支 `y` 为锚点，丧门在 `mod(y + 2, 12)`，白虎为其对冲位置，故 `baihu = mod(y + 8, 12)`。例如子年丧门寅、白虎申。来源：[S5] 所录《紫微斗数全书》安丧门白虎条。

这首先是**安置到地支宫位**的规则，不直接等于“这一天是白虎日”。如产品将所选日支与该位置比较，须另外定义为“岁前位置与日支匹配”，不得冒充原典完整历日规则。

黄黑道白虎日的月起法、正月采用节月还是农历月、交接时点，本稿暂未确定。因此 `baihu-huanghei` 标记为 `pending-source`，不提供未经选定版本的公式，也不在普通日历上线。同名的青龙等亦需另建规则集。

## 12. 实现建议与结果格式

建议先实现纯查表函数，再接界面；本稿本身不授权新增出生资料收集。

```js
// 示例结果；这里的日干甲与目标支丑是规则输入，不是某公历日期的推算。
{
  id: 'tianyi',
  ruleVersion: 'natal-common-v1',
  context: 'natal',
  anchor: { pillar: 'day', component: 'stem', value: '甲' },
  target: { pillar: 'month', component: 'branch', value: '丑' },
  matched: true,
  completeness: 'partial', // 已知年、月、日；时柱未知
  sourceIds: ['S1', 'S2']
}
```

结果至少区分 `matched`、`not-matched`、`not-evaluated`、`pending-source`。不适用或缺资料不等于“确定没有”。一个名字可有多个来源和多个命中柱；按名字合并显示时仍保留证据链。禁止将命中个数转换为吉凶总分。

第一阶段可考虑的公共日期项目：四日版魁罡、日柱旬空目标支，以及明确标注版本的节月天德／月德日匹配。个人贵人、桃花等先保留研究资料；白虎择日版本暂缓。上线前还需验证现有干支和节气计算，尤其立春、交节、午夜及不同时区边界。

### 规则准备情况

- 天德、月德：见 §6。
- 天乙、文昌、禄神、羊刃：见 §4；羊刃默认使用五阳干版。

## 17. 首版用户自定义日期匹配（实现约定）

本节记录用户后续确认的首版交互，优先于前文关于自动查表的实现建议。第一批 13 项均提供复选框、匹配类型（日干／日支／日柱）和一个可填写多个值的目标输入。输入是要在日期中寻找的干支，不是待推算的出生参照；本版本不自动从年干、日干等锚点推导目标。

用户在设置中勾选、填写目标，按“保存并计算”，再打开日期详情查看结果。未勾选项目不参与；空白或无效目标阻止保存。设置按浏览器保存，不随账户切换或云笔记同步。日柱沿用当前日历计算及当地民用日界。无需提前生成日期区间。

神为绿色、煞为红色，均有文字分类。多项命中分别显示名称，不显示“双煞”或合计数。**当启用的空亡项目匹配当日时，当日所有已匹配神煞一律不生效**，保留名称并改为灰色，显示“逢空亡，当日神煞均不生效。”空亡未勾选或未匹配时不触发该覆盖规则。这是用户选定的项目规则，不宣称为所有传统流派的统一解释。

示例：魁罡日柱目标庚辰、十恶大败日柱目标庚辰与戊戌。庚辰日显示两项；若空亡日支目标同时含辰，两项均不生效。保存目标不会触碰日记草稿。

### 17.1 无名自定义项

另加 ①–③ 三个无名自定义复选项，均可输入日干、日支或完整日柱的匹配目标；不自动归类为神或煞。勾选时目标输入加粗，日期详情仅显示命中的干支值并加粗，常态采用中性色。逢空亡时仍保留粗体，但改为灰色并标注不生效。原有已保存设置兼容，自定义项默认关闭。

### 17.2 简化输入

按用户要求移除日干／日支／日柱选择器与输入框占位提示。直接输入目标，按有效天干、地支、六十甲子组合自动识别；同一项目允许混合类型。原保存数据的目标值继续兼容，旧类型字段不再需要。

### 17.3 可搜索多选下拉框

正式首版改用可搜索多选下拉框，按天干、地支、六十甲子组合分组。选中值显示为可移除标签，不再手输目标。沿用此前保存的有效目标；无名自定义项的目标标签与日期命中保持粗体。
